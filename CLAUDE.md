# vtabs

Personal Chrome extension (Arc-style spaces and vertical tabs), loaded unpacked from a git clone on each computer. See README.md.

## Versioning

Every commit bumps the version in `manifest.json`. If the version hasn't already changed since the previous commit, increment the patch number ("Z" in X.Y.Z), e.g. 1.0.1 → 1.0.2, and include it in the same commit. The version shows on the vtabs card in `chrome://extensions`, which is how to tell whether a computer has pulled and reloaded the latest code. These are not GitHub releases; no tags or release notes needed.
